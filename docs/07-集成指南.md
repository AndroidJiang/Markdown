# AntFluid 集成指南

> 本文档介绍如何在你的 Android 项目中集成 AntFluid（FluidMarkdown）并完成基础配置。

---

## 一、集成方式

AntFluid 以**源码子模块**方式集成（不通过 Maven 发布），需要将整个 AntFluid 目录复制或引用到宿主项目中。

### 1.1 复制源码

将 `AntFluid/` 目录复制到宿主项目根目录下（或任意子目录），保留以下模块：

```
AntFluid/
├── fluid-markdown/
├── markwon-core/
├── markwon-ext-tables/
├── markwon-ext-latex/
├── markwon-ext-strikethrough/
├── markwon-ext-tasklist/
├── markwon-html/
├── markwon-image/
├── markwon-inline-parser/
└── markwon-syntax-highlight/
```

`app-sample/` 是演示 App，可以不复制。

### 1.2 配置 settings.gradle

在宿主项目的 `settings.gradle` 中 include 各模块：

```groovy
// settings.gradle
include ':fluid-markdown'
include ':markwon-core'
include ':markwon-ext-tables'
include ':markwon-ext-latex'
include ':markwon-ext-strikethrough'
include ':markwon-ext-tasklist'
include ':markwon-html'
include ':markwon-image'
include ':markwon-inline-parser'
include ':markwon-syntax-highlight'

// 如果 AntFluid 在子目录中，指定 projectDir
project(':fluid-markdown').projectDir = new File('AntFluid/fluid-markdown')
project(':markwon-core').projectDir = new File('AntFluid/markwon-core')
// ... 其他模块类似
```

### 1.3 添加依赖

在宿主 App 模块的 `build.gradle` 中：

```groovy
dependencies {
    api project(':fluid-markdown')
    // fluid-markdown 会传递依赖所有 markwon-* 模块
}
```

## 二、初始化

### 2.1 全局初始化（Application 或首次使用前）

```java
import com.fluid.afm.AFMInitializer;

// 最简初始化
AFMInitializer.init(context, null, null, null);

// 完整初始化
AFMInitializer.init(
    context,                    // Context（必填）
    backgroundTaskHandler,       // 后台任务处理器（可选，null 使用默认）
    imageHandler,               // 自定义图片加载器（可选）
    logHandler                  // 自定义日志处理器（可选）
);
```

### 2.2 自定义图片加载器

如果项目使用 Glide/Coil 等图片库，需要实现 `ImageHandler`：

```java
// 参考 app-sample 中的 MyImageHandler
public class MyImageHandler implements ImageHandler {
    @Override
    public void loadImage(String url, int width, int height,
            ImageCallback callback) {
        Glide.with(context)
            .load(url)
            .into(new CustomTarget<Drawable>(width, height) {
                @Override
                public void onResourceReady(Drawable resource, ...) {
                    callback.onSuccess(resource);
                }
                @Override
                public void onLoadFailed(@Nullable Drawable errorDrawable) {
                    callback.onError();
                }
            });
    }
}
```

## 三、基础使用

### 3.1 布局 XML

```xml
<com.fluid.afm.markdown.widget.PrinterMarkDownTextView
    android:id="@+id/markdown_view"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:textSize="15sp"
    android:textColor="#333333" />
```

### 3.2 静态渲染（一次性显示）

```java
PrinterMarkDownTextView markdownView = findViewById(R.id.markdown_view);

// 1. 初始化样式和回调
MarkdownStyles styles = MarkdownStyles.getDefaultStyles();
markdownView.init(styles, new ElementClickEventCallback() {
    @Override
    public void onLinkClick(String url) {
        // 处理链接点击
    }
    @Override
    public void onImageClick(String url) {
        // 处理图片点击
    }
    // ... 其他回调
});

// 2. 设置 Markdown 内容
markdownView.setMarkdownText("# Hello\n\nThis is **Markdown**");
```

### 3.3 流式渲染（打字机效果）

```java
PrinterMarkDownTextView markdownView = findViewById(R.id.markdown_view);
markdownView.init(styles, callback);

// 1. 设置打印参数
markdownView.setPrintParams(25, 1);  // 25ms 间隔, 每次 1 字符

// 2. 开始打印
markdownView.startPrinting(initialContent);

// 3. 追加内容（服务端持续推送时调用）
markdownView.appendPrinting(newContent, true);

// 4. 控制
markdownView.pause();       // 暂停
markdownView.resume();      // 恢复
markdownView.stopPrinting("(已停止)");  // 停止
```

### 3.4 事件回调

```java
ElementClickEventCallback callback = new ElementClickEventCallback() {
    @Override
    public void onLinkClick(String url) {
        // 链接点击
    }

    @Override
    public void onImageClick(String url) {
        // 图片点击（可跳转大图预览）
    }

    @Override
    public void onFootnoteClick(String footnoteId) {
        // 脚注点击
    }

    @Override
    public void onElementExposure(String type, String content) {
        // 元素曝光埋点
    }
};
```

## 四、样式配置

### 4.1 使用默认样式

```java
MarkdownStyles styles = MarkdownStyles.getDefaultStyles();
markdownView.init(styles, callback);
```

### 4.2 自定义样式

```java
MarkdownStyles styles = MarkdownStyles.getDefaultStyles();

// 修改链接样式
styles.linkStyle()
    .fontColor(0xFF007AFF)
    .underline(false);

// 修改代码块样式
styles.codeStyle()
    .codeFontSize(14)
    .codeBackgroundColor(0xFFF5F5F5);

// 修改表格样式
styles.tableStyle()
    .tableBlockRadius(16)
    .borderColor(0xFFDDDDDD);

// 修改标题样式（H1）
styles.setTitleStyle(0, TitleStyle.create(1.5f)
    .icon("https://cdn.example.com/h1.png"));

markdownView.init(styles, callback);
```

### 4.3 运行时更新样式

```java
MarkdownStyles newStyles = /* 新样式 */;
markdownView.getMarkdownParser().updateMarkdownStyles(newStyles);
```

## 五、RecyclerView 列表集成

### 5.1 ViewHolder

```java
public class MarkdownHolder extends RecyclerView.ViewHolder {
    private final PrinterMarkDownTextView markdownView;

    public MarkdownHolder(View itemView) {
        super(itemView);
        markdownView = itemView.findViewById(R.id.markdown_view);
    }

    public void bind(String content, boolean isStreaming) {
        markdownView.init(styles, callback);

        if (isStreaming) {
            markdownView.setPrintParams(25, 1);
            markdownView.startPrinting(content);
        } else {
            markdownView.setMarkdownText(content);
        }
    }
}
```

### 5.2 复用处理

```java
@Override
public void onViewRecycled(@NonNull MarkdownHolder holder) {
    // 停止流式打印，释放资源
    holder.markdownView.stopPrinting(null);
}
```

### 5.3 高度变化监听

```java
markdownView.setSizeChangedListener((w, h, oldw, oldh) -> {
    // 通知 RecyclerView 重新测量
    adapter.notifyItemChanged(position);
});
```

## 七、常见问题

### Q1: 图片不显示

确保实现了 `ImageHandler` 并在 `AFMInitializer.init()` 中传入。默认不包含图片加载实现。

### Q2: LaTeX 公式不渲染

检查 `markwon-ext-latex` 模块是否正确 include，以及 `jlatexmath-android` 依赖是否存在。

### Q3: 流式渲染卡顿

- 减小 `chunkSize`（建议 1-2）
- 增大 `interval`（建议 25-50ms）
- 长文本场景考虑分段渲染

### Q4: RecyclerView 中表格显示异常

- 确保设置了 `setMaxWidthForMeasure()`
- `onViewRecycled` 中调用 `stopPrinting(null)`

### Q5: 表格内链接无法点击

AntFluid 原版不支持，需要参考 egame_cloud_phone 的修改（`handleCellLinkClick` + `NonScrollingLinkMovementMethod`）。
