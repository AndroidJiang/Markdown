# 基于已有元素自定义扩展指南

> 本文档以表格为主要示例，介绍如何在不创建新语法的前提下，对已有 Markdown 元素进行功能增强和自定义扩展。

---

## 一、扩展已有元素的思路

已有元素的扩展通常不需要修改解析逻辑（Parser），而是在以下层面操作：

```
1. processMarkdown()   — 预处理原始文本（如清理、格式化）
2. SpanFactory          — 替换/追加 Span
3. NodeVisitor          — 修改 AST 遍历行为
4. Span 自身            — 修改绘制逻辑
5. afterSetText()       — setText 后的交互增强
```

---

## 二、表格扩展实战

### 场景1：给表格添加排序功能

**目标：** 用户点击表头时按该列排序。

**需要修改的文件：**

| 文件 | 操作 |
|------|------|
| `TablePlugin.java` (markwon-ext-tables) | 修改 Visitor 逻辑，记录表格数据结构 |
| `TableRowSpan.java` (markwon-ext-tables) | 修改 draw()，在表头绘制排序图标 |
| `TableBlockTitleBlockSpan.java` (markwon-ext-tables) | 可选：标题栏增加排序按钮 |
| 新建 `SortableTablePlugin.java` (fluid-markdown) | 封装排序逻辑的 Plugin |
| `MarkdownParserFactory.java` (fluid-markdown) | 注册新 Plugin |

**实现思路：**

```java
public class SortableTablePlugin extends AbstractMarkwonPlugin {

    // 存储表格原始数据，key = tableIndex
    private final Map<Integer, List<List<Cell>>> tableDataMap = new HashMap<>();

    @Override
    public void configureVisitor(@NonNull MarkwonVisitor.Builder builder) {
        // 在 TableBlock 访问时收集数据
        builder.on(TableBlock.class, (visitor, tableBlock) -> {
            int tableIndex = /* 计算当前表格索引 */;
            List<List<Cell>> rows = collectRows(tableBlock);
            tableDataMap.put(tableIndex, rows);
            // 调用原有逻辑（通过 Registry 获取 TablePlugin）
        });
    }

    // 排序方法供 Span 点击时调用
    public void sortByColumn(int tableIndex, int column, boolean ascending) {
        List<List<Cell>> data = tableDataMap.get(tableIndex);
        if (data != null) {
            data.sort((a, b) -> {
                String va = a.get(column).text.toString();
                String vb = b.get(column).text.toString();
                return ascending ? va.compareTo(vb) : vb.compareTo(va);
            });
            // 触发重新渲染
        }
    }
}
```

### 场景2：表格横向滚动

**目标：** 列数过多时可以横向滚动。

**需要修改的文件：**

| 文件 | 操作 |
|------|------|
| `TableRowSpan.java` | 修改 `getSize()` 不再均分列宽，改为按内容宽度 |
| `PrinterMarkDownTextView.java` 或外层布局 | 用 `HorizontalScrollView` 包裹 |
| 或新建 `ScrollableTableSpan.java` | 用 `ReplacementSpan` + `HorizontalScrollView` |

**实现思路（方案一：修改 TableRowSpan）：**

```java
// TableRowSpan.java 中修改 getSize()
@Override
public int getSize(Paint paint, ..., FontMetricsInt fm) {
    // 原逻辑：列宽 = 总宽 / 列数
    // 修改为：列宽 = max(minWidth, 按内容计算)
    int totalWidth = 0;
    for (Cell cell : cells) {
        int cellWidth = measureCellWidth(paint, cell.text);
        cellWidth = Math.max(cellWidth, MIN_CELL_WIDTH);
        columnWidths[i] = cellWidth;
        totalWidth += cellWidth;
    }
    // 返回总宽度（可能超出 TextView 宽度）
    return totalWidth;
}
```

**实现思路（方案二：Plugin + HorizontalScrollView）：**

更建议的方式是创建一个自定义 `ReplacementSpan`，在 `draw()` 中嵌入 `HorizontalScrollView` + 内部 `TableView`，这需要较深的 Android Span 绘制经验。

### 场景3：表格内链接可点击

**目标：** 表格单元格中的链接可以响应点击。

**需要修改的文件：**

| 文件 | 操作 |
|------|------|
| `TableRowSpan.java` | 添加 `handleCellLinkClick()` 方法 |
| `MarkdownAwareMovementMethod.java` | 修改 touch 事件分发 |

**注意：** egame_cloud_phone 项目已经实现了这个功能，参考文件：
- `egame_cloud_phone/markwon-ext-tables/.../TableRowSpan.java` — `handleCellLinkClick()`

## 三、代码块扩展实战

### 场景：给代码块添加行号

**需要修改的文件：**

| 文件 | 操作 |
|------|------|
| `CodeBlockPlugin.java` (fluid-markdown) | 修改 Visitor，在代码文本前插入行号 |
| 或 新建 `LineNumberSpan.java` | 在每行开头绘制行号 |

```java
// 方式1：简单文本插入（在 processMarkdown 中）
@Override
public String processMarkdown(@NonNull String markdown) {
    // 找到代码块，在每行前插入行号
    return addLineNumbers(markdown);
}

// 方式2：自绘 Span（更精细控制）
public class LineNumberSpan extends LeadingMarginSpan.Standard {
    private final int lineNumber;

    @Override
    public void drawLeadingMargin(Canvas c, Paint p, int x, int dir,
            int top, int baseline, int bottom, ...) {
        // 在左侧绘制行号
        c.drawText(String.valueOf(lineNumber), x, baseline, numberPaint);
    }
}
```

### 场景：代码块添加复制按钮回调

**已有支持：** `CodeBlockPlugin` 已有复制按钮图标渲染，需要添加业务回调：

```java
// fluid-markdown/.../code/CodeBlockPlugin.java
// 已有 CodeBlockTitleSpan 的复制图标
// 扩展：通过 ElementClickEventCallback 回调
callback.onCodeBlockCopyClick(codeContent);
```

## 四、链接扩展实战

### 场景：不同类型链接不同样式

**需要修改的文件：**

| 文件 | 操作 |
|------|------|
| 新建或修改 linkPlugin | 在 SpanFactory 中判断 URL 类型 |

```java
plugins.add(new AbstractMarkwonPlugin() {
    @Override
    public void configureSpansFactory(@NonNull MarkwonSpansFactory.Builder builder) {
        builder.setFactory(Link.class, (config, props) -> {
            String href = CoreProps.LINK_DESTINATION.require(props);

            if (href.startsWith("tel:")) {
                return new PhoneLinkSpan(href, callback);
            } else if (href.startsWith("mailto:")) {
                return new EmailLinkSpan(href, callback);
            } else {
                return new LinkClickSpan(config.theme(), href, callback);
            }
        });
    }
});
```

## 五、列表扩展实战

### 场景：自定义 bullet 图标

通过 `MarkdownStyles` 即可实现，无需修改源码：

```java
MarkdownStyles styles = MarkdownStyles.getDefaultStyles();

// 所有层级使用自定义形状
Shape customShape = new Shape();
customShape.type(Shape.TYPE_ICON);
customShape.icon("https://cdn.example.com/bullet.png");
customShape.size(8);
styles.baseBullet().setShape(customShape);

// 不同嵌套层级不同样式
BulletStyle level1 = BulletStyle.create();
level1.setShape(circleShape);
styles.setBulletStyle(0, level1);

BulletStyle level2 = BulletStyle.create();
level2.setShape(squareShape);
styles.setBulletStyle(1, level2);
```

## 六、扩展检查清单

当你要扩展某个已有元素时，按以下清单检查：

```
□ 1. 确认扩展层面
   □ 只需要改外观？ → 修改 MarkdownStyles
   □ 需要改 Span 行为？ → 替换 SpanFactory 或修改 Span 类
   □ 需要改 AST 遍历？ → 修改 NodeVisitor
   □ 需要预处理文本？ → 修改 processMarkdown

□ 2. 选择扩展方式
   □ 新建 Plugin 继承 AbstractMarkwonPlugin
   □ 在现有 Plugin 中修改
   □ 直接修改 Span 类

□ 3. 注册 Plugin
   □ MarkdownParserFactory.getDefaultPlugins() 中添加
   □ 注意插件顺序

□ 4. 流式渲染兼容
   □ 如果 Span 有状态，是否需要实现 StreamOutStateObserver？
   □ 流式模式下缓存是否需要清理？

□ 5. 测试
   □ 普通渲染模式
   □ 流式打字机模式
   □ RecyclerView 列表复用场景
```

## 七、常见扩展场景速查表

| 场景 | 扩展层面 | 修改文件 |
|------|----------|----------|
| 改表格颜色/圆角 | MarkdownStyles | 无需改源码 |

| 表格横向滚动 | Span | 修改 TableRowSpan.getSize/draw |

| 代码块行号 | Plugin 或 Span | 新建 LineNumberSpan |
| 代码块复制回调 | Plugin | 修改 CodeBlockPlugin |
| 不同类型链接不同样式 | SpanFactory | 新建 Plugin |
| 自定义 bullet 图标 | MarkdownStyles | 无需改源码 |
| 标题添加锚点 | NodeVisitor | 新建 Plugin |
| 图片点击放大 | SpanFactory | 修改 imagePlugin |
| 自定义引用块样式 | MarkdownStyles | 无需改源码 |
