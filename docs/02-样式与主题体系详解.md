# 样式与主题体系详解

> 本文档详细介绍 AntFluid 的样式配置体系，包括 `MarkdownStyles` 聚合容器和 `MarkwonTheme` 渲染主题的关系，以及每种样式类的字段说明。

---

## 一、双层样式架构

AntFluid 的样式体系分两层：

```
MarkdownStyles (业务层 — 结构化配置)
    │
    │  setStyles() / updateStyles()
    ▼
MarkwonTheme (渲染层 — Span 绘制时读取)
    │
    │  getter / apply*()
    ▼
各类 Span 的 draw() / updateDrawState()
```

### 为什么分两层？

- **MarkdownStyles** — 面向业务开发者，链式配置 API，字段语义清晰（`fontSize`、`fontColor`、`lineHeight` 等）
- **MarkwonTheme** — 面向渲染引擎，持有样式引用并提供 `apply*()` 方法给各 Span 调用

开发者只需关注 `MarkdownStyles`，不需要直接操作 `MarkwonTheme`。

---

## 二、MarkdownStyles — 样式聚合容器

**路径：** `markwon-core/src/main/java/com/fluid/afm/styles/MarkdownStyles.java`

Fluent Builder 风格的样式容器，管理所有 Markdown 元素的样式配置。

### 2.1 包含的子样式

| 字段 | 类型 | 控制元素 |
|------|------|----------|
| `paragraph` | `ParagraphStyle` | 正文字号、颜色、行高、段间距 |
| `horizonRule` | `HorizonRuleStyle` | 水平分割线 |
| `link` | `LinkStyle` | 链接颜色、下划线、加粗、图标 |
| `table` | `TableStyle` | 表格圆角、边框、表头/表体背景色、字号 |
| `code` | `CodeStyle` | 行内代码/代码块背景、边框、字号、字体 |
| `blockQuote` | `BlockQuoteStyle` | 引用块竖线颜色/宽度/圆角 |
| `titleStyles` | `TitleStyle[6]` | H1–H6 标题字号系数/px、图标、段间距 |
| `orderStyles` | `Map<Integer, OrderStyle>` | 按嵌套层级的有序列表样式 |
| `baseOrder` | `OrderStyle` | 有序列表兜底样式 |
| `bulletStyles` | `Map<Integer, BulletStyle>` | 按嵌套层级的无序列表样式 |
| `baseBullet` | `BulletStyle` | 无序列表兜底样式 |
| `footnote` | `FootnoteStyle` | 脚注上标样式 |
| `underline` | `UnderlineStyle` | 自定义下划线（Ant 特色） |

### 2.2 使用方式

```java
// 方式1：使用产品级默认样式
MarkdownStyles styles = MarkdownStyles.getDefaultStyles();

// 方式2：在默认样式上修改
styles.linkStyle().fontColor(0xFF007AFF).underline(true);
styles.codeStyle().codeFontSize(14);
styles.setTitleStyle(0, TitleStyle.create(1.5f).icon("https://icon_url"));

// 方式3：完全自定义
MarkdownStyles styles = new MarkdownStyles();
styles.paragraphStyle().fontSize(16).fontColor(0xFF333333);
// ... 配置各项
```

### 2.3 默认样式值（`getDefaultStyles()`）

| 模块 | 关键默认值 |
|------|-----------|
| **段落** | 字号 30rpx，颜色 `#333333`，行高 48rpx，段间距 10px |
| **水平线** | 高 0.5px，颜色 `#E2E5F3`，上下边距 16px/6px |
| **链接** | 无下划线，颜色 `#1296DB` |
| **有序列表** | leading 1px，加粗，间距 5px |
| **无序列表** | leading 1px，间距 8px，圆形 bullet `#13113E` 5px |
| **脚注** | 颜色 `#999999`，背景 `#141F3B63`，加粗，size 32rpx，fontSize 20rpx |
| **引用块** | 线色 `#EEEEEE`，文字 `#999999`，线宽 4px，圆角 2px，线边距 40rpx |
| **表格** | 圆角 24rpx，标题色 `#999999`，标题背景 `#EDEFF3`，表头背景 `#F6F7F9`，body 白底 |
| **代码** | 行内色 `#2980B9`，块级 `#333333` 26rpx，MONOSPACE 字体 |
| **下划线** | 宽 12rpx，颜色 `#7A1677FF` |
| **标题** | H1=1.3x, H2=1.2x, H3=1.1x, H4–H6=1.0x |

## 三、各 Style 类详解

### 3.1 ParagraphStyle — 段落

最基础的文字样式，被 `TitleStyle`、`BlockQuoteStyle` 等组合复用。

| 字段 | 类型 | 默认值 | 含义 |
|------|------|--------|------|
| `fontSize` | `float` | `0` | 字号（px 或相对系数） |
| `fontColor` | `int` | `0` | 文字颜色（0 不覆盖） |
| `lineHeight` | `int` | `0` | 行高（px） |
| `paragraphSpacing` | `int` | `-1` | 段后间距（-1 未设置） |

### 3.2 TitleStyle — 标题

内嵌 `ParagraphStyle`，支持**相对系数**和**绝对 px** 两种字号模式。

| 字段 | 类型 | 默认值 | 含义 |
|------|------|--------|------|
| `icon` | `String` | `null` | 标题图标 URL |
| `sizeType` | `int` | `0` | 0=相对系数，1=绝对 px |
| `paragraph` | `ParagraphStyle` | 新建 | 内嵌段落样式 |
| `typeface` | `Typeface` | `null` | 自定义字体（null 则 fakeBold） |
| `paragraphSpacingBefore` | `int` | `0` | 标题前段间距 |

**字号计算规则：**
- `sizeType=0`（相对）：`paint.textSize * fontSize`（如 1.3 倍）
- `sizeType=1`（绝对）：直接使用 `fontSize` px 值

**默认 6 级标题系数：** `[1.3f, 1.2f, 1.1f, 1.0f, 1.0f, 1.0f]`

### 3.3 LinkStyle — 链接

| 字段 | 类型 | 默认值 | 含义 |
|------|------|--------|------|
| `fontColor` | `int` | `0` | 颜色（0 用 TextPaint.linkColor） |
| `space` | `int` | `0` | 图标间距 |
| `icon` | `String` | `null` | 链接图标 URL |
| `underline` | `boolean` | `true` | 是否下划线 |
| `isBold` | `boolean` | `false` | 是否加粗 |

### 3.4 TableStyle — 表格

表格样式最复杂，含三套 `TableCell`（标题行/表头/正文），实现 `Parcelable`。

| 字段 | 类型 | 默认值 | 含义 |
|------|------|--------|------|
| `title` | `TableCell` | 白底 | 表格标题栏单元格样式 |
| `header` | `TableCell` | 色 `#999999` 26sp | 表头行样式 |
| `body` | `TableCell` | 色 `#333333` 26sp | 正文行样式 |
| `cellTopBottomPadding` | `int` | `0` | 单元格上下 padding |
| `cellLeftRightPadding` | `int` | `12dp` | 单元格左右 padding |
| `drawBorder` | `boolean` | `true` | 是否绘制边框 |
| `borderColor` | `int` | `0` | 边框颜色 |
| `borderWidth` | `int` | `-1` | 边框宽度 |
| `tableBlockRadius` | `int` | `24rpx` | 表格块圆角 |
| `titleBarHeight` | `int` | `40dp` | 标题栏高度 |
| `columnDefaultMaxWidth` | `float` | `0` | 默认列最大宽度 |
| `columnFirstMaxWidth` | `float` | `0` | 首列最大宽度 |

**`TableCell` 子字段：**

| 字段 | 含义 |
|------|------|
| `backgroundColor` | 背景色 |
| `fontSize` | 字号 |
| `fontColor` | 文字色 |

### 3.5 CodeStyle — 代码

行内代码与代码块共用样式类，实现 `Parcelable`。

| 字段 | 含义 | 默认值 |
|------|------|--------|
| `inlineFontColor` | 行内代码文字色 | `0xFF333333` |
| `inlineFontSize` | 行内代码字号 | `15dp` |
| `inlineBackgroundColor` | 行内代码背景色 | `0x1E1F3B63` |
| `inlineBackgroundRadius` | 行内代码圆角 | `4dp` |
| `codeFontColor` | 代码块文字色 | `0xFF333333` |
| `codeFontSize` | 代码块字号 | `13dp` |
| `codeBackgroundColor` | 代码块背景色 | `Color.WHITE` |
| `codeBackgroundRadius` | 代码块圆角 | `12dp` |
| `titleFontColor` | 标题栏文字色 | `0xFF999999` |
| `titleBackgroundColor` | 标题栏背景色 | `0xFFEDEFF3` |
| `borderColor` | 边框颜色 | `0xFFDEDEDE` |
| `borderWidth` | 边框宽度 | `0.5dp` |
| `lightIcon` | 复制按钮浅色主题 | `true` |
| `drawBorder` | 是否绘制边框 | `true` |
| `codeTypeface` | 代码字体 | `MONOSPACE` |
| `showTitle` | 是否显示标题栏 | `true` |

### 3.6 BlockQuoteStyle — 引用块

| 字段 | 含义 | 默认值 |
|------|------|--------|
| `lineWidth` | 左侧竖线宽度 | `4dp` |
| `lineColor` | 竖线颜色（0 则用文字色+25% alpha） | `0` |
| `lineCornerRadius` | 竖线圆角 | `-1` |
| `lineMargin` | 竖线与内容间距 | `24dp` |
| `bottomMargin` | 底部间距 | `8dp` |
| `paragraph` | 引用文字样式 | 新建 ParagraphStyle |

### 3.7 OrderStyle — 有序列表

| 字段 | 含义 | 默认值 |
|------|------|--------|
| `fontColor` | 序号文字颜色 | `0` |
| `fontSize` | 序号字号 | `0` |
| `shape` | 序号形状（icon/rectangle） | `null` |
| `leading` | 序号区域宽度 | `12px` |
| `leadingSpacing` | 序号与正文间距 | `12px` |
| `bold` | 序号是否加粗 | `true` |

### 3.8 BulletStyle — 无序列表

| 字段 | 含义 | 默认值 |
|------|------|--------|
| `shape` | bullet 形状 | `null` |
| `leadingSpacing` | bullet 与正文间距 | `-1` |
| `leading` | bullet 区域宽度 | `0` |

## 四、MarkwonTheme — 渲染主题

**路径：** `markwon-core/src/main/java/io/noties/markwon/core/MarkwonTheme.java`

### 4.1 职责

持有 `MarkdownStyles` 的各子样式引用，并提供 `apply*()` 方法供各 Span 在绘制时调用。

### 4.2 构建流程

```java
MarkwonTheme theme = MarkwonTheme.emptyBuilder()
    .setStyles(markdownStyles)      // 注入样式
    .setTextView(textView)          // 绑定 TextView
    .build(pluginList);             // 让各 Plugin 调用 configureTheme
```

### 4.3 Theme 如何读取样式

`updateStyles(MarkdownStyles styles)` 方法逐一取出各子样式保存引用：

```java
public void updateStyles(MarkdownStyles styles) {
    this.paragraph = styles.paragraphStyle();
    this.link = styles.linkStyle();
    this.table = styles.tableStyle();
    this.titleStyles = styles.titleStyles();
    // ... 其余字段
}
```

### 4.4 关键 apply 方法

| 方法 | 调用方 | 作用 |
|------|--------|------|
| `applyLinkStyle(TextPaint)` | `LinkClickSpan` 等 | 设置链接颜色/下划线/加粗 |
| `applyBlockQuoteStyle(Paint)` | `BlockQuoteSpan` | 设置引用线颜色 |
| `applyInlineCodeTextStyle(Paint)` | `RoundedBackgroundSpan` | 行内代码字号/颜色/字体 |
| `applyCodeBlockTextStyle(Paint)` | `CodeBlockSpan` | 代码块字号/颜色/字体 |
| `getTitleStyle(level)` | `HeadingSpan` | 获取指定级别标题样式 |
| `getBulletStyle(level)` | `BulletListItemSpan` | 获取指定层级 bullet 样式 |
| `orderBean(level)` | `OrderedListItemSpan` | 获取指定层级有序列表样式 |
| `getTableStyle()` | `TableRowSpan` | 获取表格样式 |
| `getParagraphBreakHeight()` | `ParagraphSpacingSpan` | 获取段间距 |

## 五、运行时样式热更新

```java
// 更新样式
MarkdownStyles newStyles = MarkdownStyles.getDefaultStyles();
newStyles.linkStyle().fontColor(0xFF007AFF);

// 通过 MarkdownParser 热更新
markdownParser.updateMarkdownStyles(newStyles);
// 内部会: theme.updateStyles(newStyles) → textView.invalidate()
```

## 六、自定义样式实战示例

### 示例1：修改表格圆角和颜色

```java
MarkdownStyles styles = MarkdownStyles.getDefaultStyles();
TableStyle table = styles.tableStyle();
table.tableBlockRadius(Utils.dpToPx(16));       // 圆角 16dp
table.borderColor(0xFFCCCCCC);                  // 边框颜色
table.header().backgroundColor(0xFFF0F0F0);     // 表头背景
table.body().fontColor(0xFF666666);             // 正文字色
```

### 示例2：自定义标题样式

```java
MarkdownStyles styles = MarkdownStyles.getDefaultStyles();
// H1: 绝对字号 24px + 自定义图标
styles.setTitleStyle(0, TitleStyle.create(24f)
    .sizeType(1)  // 绝对 px
    .icon("https://cdn.example.com/h1_icon.png")
    .paragraphSpacingBefore(16));

// H2: 1.5 倍相对字号
styles.setTitleStyle(1, TitleStyle.create(1.5f));
```

### 示例3：深色主题

```java
MarkdownStyles darkStyles = new MarkdownStyles();
darkStyles.paragraphStyle().fontColor(0xFFE0E0E0);
darkStyles.linkStyle().fontColor(0xFF64B5F6);
darkStyles.codeStyle()
    .codeFontColor(0xFFE0E0E0)
    .codeBackgroundColor(0xFF1E1E1E)
    .titleBackgroundColor(0xFF2D2D2D);
darkStyles.tableStyle()
    .textColor(0xFFE0E0E0)
    .header().backgroundColor(0xFF2D2D2D);
darkStyles.blockQuoteStyle()
    .lineColor(0xFF555555)
    .paragraph().fontColor(0xFF999999);
```
